# Заметки + Цитата

## Краткое описание

Простое мобильное приложение: пользователь ведёт список коротких текстовых заметок с сохранением на устройстве и просматривает цитату дня из встроенного списка (7 цитат, каждый календарный день — своя).

## Тема приложения

Заметки + цитата — аналог блокнота и «цитаты дня» без сложной логики: нет регистрации, категорий и синхронизации с облаком. Подходит для MVP: несколько экранов, ввод текста, список, локальное хранение, переключение вкладок.

## Основные функции

- добавление заметки (поле ввода + кнопка «Добавить»);
- просмотр списка заметок с датой;
- удаление заметки;
- сохранение заметок на устройстве (`shared_preferences`);
- просмотр цитаты дня (7 цитат, смена по календарному дню);
- кнопка «Цитата дня» на вкладке «Цитата»;
- переключение вкладок «Заметки» / «Цитата»;
- экран «О приложении» (дополнительный маршрут).

## Структура экранов

| Экран | Содержимое |
|-------|------------|
| Заметки (главный) | AppBar, поле ввода, кнопка «Добавить», список заметок, нижнее меню |
| Цитата | AppBar, кнопка «Цитата дня», текст цитаты и автор, нижнее меню |
| О приложении | AppBar, информационный текст (открывается поверх основных экранов) |

Общая оболочка: одна `Scaffold` с `BottomNavigationBar` и двумя вкладками в `IndexedStack`.

## Навигация

1. **BottomNavigationBar** — переключение между «Заметки» и «Цитата» (`IndexedStack`).
2. **Navigator.push** — кнопка в AppBar открывает «О приложении»; возврат — «Назад».

## Сценарии использования

1. **Добавить заметку:** вкладка «Заметки» → ввести текст → «Добавить» → запись в списке → сохранение на устройстве.
2. **Удалить заметку:** на вкладке «Заметки» нажать иконку удаления у строки.
3. **Прочитать цитату дня:** вкладка «Цитата» → цитата на сегодня → при необходимости «Цитата дня».
4. **О приложении:** кнопка в шапке → текст → «Назад».
