Название проекта: Заметки + Цитата


Краткое описание: простое мобильное приложение: пользователь ведёт список коротких текстовых заметок с сохранением на устройстве и просматривает цитату дня из встроенного списка (7 цитат, каждый календарный день — своя). Тема выбрана как лёгкая в реализации и достаточная для лабораторных работ по вёрстке, навигации и данным.


Тема приложения: заметки + цитата — аналог блокнота и «цитаты дня» без сложной логики: нет регистрации, категорий и синхронизации с облаком. Подходит для MVP: несколько экранов, ввод текста, список, локальное хранение, переключение вкладок.


Основные функции:
добавление заметки (поле ввода + кнопка «Добавить»)
просмотр списка заметок с датой
удаление заметки
сохранение заметок на устройстве (`shared_preferences`)
просмотр цитаты дня (7 цитат в приложении, смена по календарному дню)
кнопка «Цитата дня» на вкладке «Цитата»
переключение вкладок «Заметки» / «Цитата»
экран «О приложении» (дополнительный маршрут)


Структура экранов:
Экран             | Содержимое                                                         |

Заметки (главный) | AppBar, поле ввода, кнопка «Добавить», список заметок, нижнее меню |
Цитата            | AppBar, кнопка «Цитата дня», текст цитаты и автор, нижнее меню     |
О приложении      | AppBar, информационный текст (открывается поверх основных экранов) |

Общая оболочка: одна `Scaffold` с `BottomNavigationBar` и двумя вкладками в `IndexedStack`.

Навигация:

1. BottomNavigationBar — переключение между «Заметки» и «Цитата»; состояние вкладок сохраняется (`IndexedStack`).
2. Navigator.push — иконка в AppBar открывает экран «О приложении»; возврат — кнопка «Назад» в AppBar или системная «Назад».


Сценарии использования:

1. Добавить заметку: вкладка «Заметки» - ввести текст - «Добавить» - запись в списке - сохранение на устройстве.
2. Удалить заметку: на вкладке «Заметки» нажать на иконку удаления у нужной строки.
3. Прочитать цитату дня: вкладка «Цитата» - при открытии показывается цитата на сегодня - при необходимости «Цитата дня».
4. О приложении: нажать кнопку в шапке - прочитать текст - вернуться «Назад» на предыдущую вкладку.
